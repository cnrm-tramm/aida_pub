Ligne de commande

Pour obtenir de l'aide, taper la commande vista -h. On obtient le résultat suivant :

usage: vista [-h] [-v] [-l] [-c] [-b] [-f FILE] [-s START] [-e END] [-m MONTH] [-o OUTPUT]

optional arguments:
   -h, --help show this help message and exit
   -v, --version affiche la version de vista
   -l, --list affiche la liste des attributs configurables
   -c, --console active la console vista
   -b, --batch utilisation de vista en mode batch
   -f FILE, --file FILE fichier de configuration .vista
   -s START, --start START
     date de début : AAAAMMJJ(MISS) (à utiliser obligatoirement avec l'option --end)
   -e END, --end END   date de fin : AAAAMMJJ(MISS) (à utiliser obligatoirement avec l'option --start)
   -m MONTH, --month MONTH
     mois : AAAAMM (option prioritaire sur --start et --end
   -o OUTPUT, --output OUTPUT
     fichier de sortie (.pdf | .png | .ps)
