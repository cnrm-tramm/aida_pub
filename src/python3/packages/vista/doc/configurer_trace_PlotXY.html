Configurer un tracé PlotXY




Utiliser l'info-bulle sur le nom des différents paramètres de configuration pour obtenir des informations.

Plateforme : le menu déroulant de sélection de la plateforme propose un mode de sélection avancé. Pour cela, entrer la ou les premières lettres de la plateforme pour n'avoir que les plateformes correspondantes proposées, comme l'illustre l'image ci-dessous :


Paramètre : le menu déroulant de sélection d'un paramètre se présente en cascade à 3 niveaux :

  • famille : la famille AIDA à laquelle appartient le paramètre (tpr, hum, pre, ...).
  • fréquence : la fréquence du paramètre avec la nomenclature AIDA (%60=1min, %720=12min, 20=20Hz, 50=50Hz).
  • nom : nom du paramètre.

Noter : lorsque la liste des paramètres est très longue, on peut utiliser les touches de défilement des pages pour facilter la recherche.


Calculette : cf § Opération sur les données.


Couleur : cliquer sur le bouton pour ouvrir la boîte de sélection des couleurs :



Sélectionner une couleur avec la roue : choisir la teinte en faisant tourner la roue ou en cliquant sur le cercle. Choisir ensuite la couleur en cliquant dans le triangle ou en déplacant le curseur rond à l'intérieur du triangle.
Sélectionner une couleur avec la palette : la palette propose un choix prédéfini de couleurs. Les 5 premières sont fixes. Les autres couleurs correspondent aux couleurs déjà utilisées dans le document, ce qui permet de conserver les mêmes couleurs d'un graphique à l'autre si on le souhaite.
Les infos-bulles sont également disponibles dans cette boîte.


Trait : Texture du tracé : si aucun est sélectionné le tracé est invisible sauf si un marqueur a été choisi.


Epaisseur : Epaisseur du tracé.


Marqueur : Vista permet de tracer à l'aide de marqueurs, visibles lorsque le paramètre trait est positionné à aucun.


Régression : Trace la droite de régression et affiche les coefficients de la droite ainsi que le coefficient de regression R.


Affichage conditionnel : cf § Affichage conditionnel.


Filtrer les données : Les conditions définies pour l'affichage conditionnel servent de filtre pour les données. La régression est recalculée avec ces données filtrées.
