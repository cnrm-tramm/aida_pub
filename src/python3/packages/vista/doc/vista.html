Vista c'est quoi ?

VIsualisation des Séries Temporelles AIDA



Principe

Vista est un outil d'aide à la création de fichiers de configuration qui permettent de produire des documents graphiques représentant les données produites par le système AIDA.
L'interface graphique Vista permet non seulement de construire les documents mais aussi de visualiser les données sur un intervalle de temps.

Les fichiers de configuration peuvent ensuite être utilisés par vista lancé en ligne de commande pour produire les documents. Ce lancement peut être automatique dans un système de type crontab.


Vista fait partie du système AIDA et ne peut fonctionnner en dehors de celui-ci.
