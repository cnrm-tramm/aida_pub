Package readers
----------------

Ce package contient des modules de lecture de fichiers de données :
-csv_like : fichiers de type csv
-eddypro : fichiers générés par le logiciel eddy-pro
-ce376 : fichiers du lidar cimel
-pads : fichiers du pads

INSTALL
-------

il suffit que le répertoire readers soit dans PYTHONPATH

Documentation
-------------

nécessite sphinx
pour créer le fichier doc/index.html :
 cd readers/doc
 make doc_package
