Configuration de la console (XTerm)

  1. Éditer le fichier 
    ~/.Xresources
  2. Ajouter les lignes : 
    !  *************************
!  xrdb -remove -all
!  xrdb -load ~/.Xresources
!  *************************
xterm*geometry: 150x24
xterm*faceName: Monospace
xterm*faceSize: 12
xTerm*background: black
xTerm*foreground: white
xterm*allowTitleOps: false
!xterm*renderFont: true
  3. dans un terminal, passer les 2 commandes suivantes : 
    xrdb -remove -all
xrdb -load ~/.Xresources
