L'onglet Informations

Il permet de visualiser les informations disponibles sur l'élément sélectionné dans la navigation en cliquant sur le bouton «afficher / masquer» correspondant :


  • les Métadonnées de la plateforme (plateformes fixes uniquement)
  • les Campagnes dans lesquelles la plateforme a été engagée.
  • les Métadonnées de la l'acquisition lorsqu'une acquisition est sélectionnée.
  • les Métadonnées du vecteur lorsqu'un vecteur est sélectionné.

note : la présentation des informations disponibles dans cet onglet dépend du «mode de navigation» choisi.
