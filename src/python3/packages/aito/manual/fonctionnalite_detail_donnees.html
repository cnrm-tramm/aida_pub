L'onglet Données

L'onglet Données

Il est activé lorsqu'un vecteur est sélectionné dans la navigation.
Il permet de visualiser les informations sur le vecteur dans la partie droite.
La partie droite est divisée en trois parties :


  • Aperçu des données du vecteur
  • Outils applicables au vecteur
    (voir document de référence AIDA : user.pdf)
  • Informations sur le vecteur
