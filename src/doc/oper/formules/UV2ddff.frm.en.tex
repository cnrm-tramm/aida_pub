%%%% Vent U et V, en DD et FF
$FF = \sqrt{ U^2 + V^2 } $ 

$\text{If } V=0 \text{ then } DD =
\begin{cases}
 0 & \text{if } U=0 \\
 -\pi /2 & \text{if } U < 0 \\
 \pi /2 & \text{if } U > 0 \\
\end{cases}
$

else if $V > 0$ then $DD = \arctan (U / V) + \pi$ 

else if $V < 0$ then $DD = \arctan (U / V)$  

Eventually, $DD = 180/\pi . DD$
