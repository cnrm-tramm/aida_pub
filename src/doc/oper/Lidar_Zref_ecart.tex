
\section{Estimation de l'altitude de la rétro-diffusion moléculaire}

\itemstyle{Op\'erateur~:} \operfmt{Lidar\_Zref\_ecart}
\index{Lidar\_Zref\_ecart}

%%%%%OBJET%%%%
\itemstyle{Objet~:}
Pour un tir lidar vers le haut, cet opérateur estime l'altitude à partir de laquelle
on considère que la rétro-diffusion est uniquement moléculaire. Cette altitude est utilisée comme référence dans d'autres opérateurs pour inverser le signal lidar.
