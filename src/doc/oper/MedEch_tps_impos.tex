\section{Échantillonnage (et médiane) d'une variable sur une nouvelle base
de temps}

\itemstyle{Op\'erateur~:} \textsf{MedEch\_tps\_impos}
\index{MedEch\_tps\_impos}

%%%%%OBJET%%%%
\itemstyle{Objet~:}
Cette fonction calcule, pour chaque instant $t$ d'une
base de temps "time\_out", 
une variable "X\_out", contenant la médiane des
valeurs de  "X\_in" entre $t$-écart\_avant et $t$+écart\_après.

Aucune supposition n'est faite sur la régularité de
l'échantillonnage des 2 variables.
Il est cependant nécessaire que time\_in (le temps de X\_in) soit  trié par ordre
croissant.
