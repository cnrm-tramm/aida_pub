\section{Vent horizontal à partir des vitesses dans le repère
mobile (unités automatiques)}
%Composantes horizontales du vent à partir des vitesses dans le repère
%avion avec reconnaissance de l'unité}

\itemstyle{Op\'erateur~:} {\sf CalcVent\_h\_repav\_auto\_unit}
\index{CalcVent\_h\_repav\_auto\_unit}

%%%%%OBJET%%%%
\itemstyle{Objet~:}
Calcul simplifié d'un vent horizontal, à partir
de vitesses exprimées dans un repère lié à une plate-forme mobile. Le
 calcul est effectué dans le repère lié au mobile, puis une rotation des
composantes les amène dans le repère géographique local (ENU).
Ce calcul n'est valide que lorsque le mobile se déplace à plat.\newline
Cet opérateur travaille avec les différents types d'unités dans la
mesure où celles-ci restent homogènes. Il faut lui passer en argument
l'unité de mesure des angles.
