\section{Calcul du pourcentage d'une valeur de «\textit{flag}» donnée sur une base de temps donnée.}

\itemstyle{Op\'erateur~:} \textsf{Flag\_to\_percent}
\index{Flag\_to\_percent}

%%%%%OBJET%%%%
\itemstyle{Objet~:}
Pour chaque période de la nouvelle base de temps, on compte le nombre de flags
correspondant à la valeur de flag passée dans le vecteur d'entrée et on calcule le 
pourcentage.
