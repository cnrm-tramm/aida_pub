\section{Composantes horizontales du vent à partir des vitesses dans le 
repère mobile}

\itemstyle{Op\'erateur~:} {\sf CalcVent\_h\_repav}
\index{CalcVent\_h\_repav}

%%%%%OBJET%%%%
\itemstyle{Objet~:}
 Calcul simplifié d'un vent horizontal, à partir
de vitesses exprimées dans le repère d'une plate-forme mobile
(avion, bateau, ...) . Le calcul est
effectué dans le repère lié au mobile, puis une rotation des
composantes les amène dans le repère géographique local (ENU).
Ce calcul n'est valide que lorsque le mobile est horizontal.
