\section{Sélection dans un vecteur selon la valeur et les variations d'un second vecteur (\texttt{float})}

\itemstyle{Opérateur~:} \operfmt{select\_X\_selon\_YvarY}
\label{OP-select_X_selon_YvarY}
\index{select\_X\_selon\_YvarY}

%%%%%OBJET%%%%
\itemstyle{Objet~:}
Sélection des données d'un vecteur X selon les critères suivant appliqués à un second vecteur Y de type \texttt{float} :
\begin{itemize}
\item valeur comprise dans une gamme donnée.
\item pas de variation depuis un temps $\tau_{ap}$ et avant l'instant $t+\tau_{av}$
\end{itemize}
