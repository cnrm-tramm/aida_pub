\section{Rotation 2D vers le repère porté par le vent moyen appliquée sur des paliers temporels}

\itemstyle{Opérateur~:} \operfmt{Rotat\_2D\_rep\_vent\_moy\_paliers}
\index{Rotat\_2D\_rep\_vent\_moy\_paliers}

%%%%%OBJET%%%%
\itemstyle{Objet~:}
Calcul des 3 composantes du vecteur-vent dans 
un repère porté par le vent moyen, qui vérifie (si U est le module du vent): 
\[
\begin{array}{c}
\overline{u} = U\\
\overline{v} = 0\\
\overline{w} = 0\\
\end{array}
\]
Chaque moyenne est calculée sur des séquences de temps définies dans $time\_paliers$ ; 
Dans la détermination des flux par la méthode des covariances, cet 
opérateur est utilisé avant le detrending (qui enlève le signal basse
fréquence ou la tendance), et avant le calcul des covariances.
Cet opérateur permet de traiter des données de type vol (avion, ballon captif, ...)
pour lesquelles ont été définies des séquences temporelles (notamment des paliers).
