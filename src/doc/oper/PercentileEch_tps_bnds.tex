\section{Échantillonnage et percentile par rapport a val\_{seuil} d'une variable sur une nouvelle base
de temps donnée par un time\_{bnds}}

\itemstyle{Op\'erateur~:} \operfmt{PercentileEch\_tps\_bnds}
\index{PercentileEch\_tps\_bnds}

%%%%%OBJET%%%%
\itemstyle{Objet~:}
Cette fonction calcule, pour chaque instant $t$ d'une
base de temps $time_{out}$, 
une variable $X_{out}$, contenant le percentile associé a un vecteur 
de valeurs de  $X_{in}$ entre les bornes données par le $time_{bnds}$ associé à $time_{out}$.
Aucune supposition n'est faite sur la régularité de
l'échantillonnage des 2 variables. Il est cependant nécessaire
que $time_{in}$ (le temps de $X_{in}$) soit "à peu près" trié par ordre
croissant.
